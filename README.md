# .github

Public organization profile for [MIDDAG](https://github.com/middag-io).

The file `profile/README.md` is displayed on the [organization's GitHub page](https://github.com/middag-io).

The files `SECURITY.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `.github/ISSUE_TEMPLATE/` and `pull_request_template.md` are the defaults for every public repository of the organization that has no file of its own.
